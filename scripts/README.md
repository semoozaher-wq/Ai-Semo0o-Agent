# Scripts

هذه الأدوات تساعد في تجهيز وربط بيانات الأجزاء العضلية.

## فحص قاعدة البيانات

```bash
node scripts/validate-pain-map.js data/painMap.json
```

يدعم الفحص الشكل الحالي للمناطق العامة، ويدعم الشكل التفصيلي الذي يحتوي على:

```text
groups + muscles
```

## إنشاء قالب بيانات تشريحية

```bash
node scripts/generate-anatomy-template.js data/anatomy.template.json
```

ينشئ ملفًا يحتوي على مثالين فقط كنقطة بداية. لا يعتبر هذا الملف قائمة الـ317 جزءًا النهائية؛ يجب استبدال الأمثلة بالـIDs الحقيقية المستخرجة من ملف SVG أو المكتبة المرخصة.

## توليد الـ317 جزءًا من المكتبة المثبتة

المشروع يحتوي الآن على مكتبة `react-native-body-parts-anatomy@1.2.0` التي تتضمن 317 fragment فعليًا. لتوليد ملف البيانات كاملًا شغّل:

```bash
npm run generate:anatomy
npm run validate:pain-map
```

سينتج الأمر الملف:

```text
data/anatomyPainMap.json
```

ويحتوي على 317 سجلًا و23 مجموعة. البيانات الطبية المولدة أولية وموسومة `needs_medical_review`؛ يجب مراجعة الأسباب والتحذيرات والتوصيات طبيًا قبل نشر التطبيق.

## قواعد مهمة

- يجب أن يكون لكل جزء `id` ثابت.
- يجب ألا تتكرر IDs.
- يجب أن يتطابق ID الموجود في SVG مع المفتاح في JSON.
- لا تضف تحذيرًا أو توصية طبية قبل مراجعتها من طبيب مختص.
