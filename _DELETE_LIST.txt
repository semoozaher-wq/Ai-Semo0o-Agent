# DELETE LIST — Ai-Semo0o-Agent — Cycle 2

احذف الملفات/المجلدات التالية من الـ repository (هي مكررة/ميتة/ناتجة عن البناء ولا يجب تتبعها في Git).

## 1) مجلد البناء `dist/` (72 ملفًا) — ناتج بناء ثابت (static build artifacts)
السبب: `dist/` ناتج عن `expo export`/البناء ويجب ألا يُرفع إلى Git. وهو مضاف أصلًا إلى `.gitignore` (سطر `dist/`)، لكنه كان متتبَّعًا بالخطأ.
الإجراء:
```
git rm -r --cached dist
```
(تم تنفيذه بالفعل محليًا — احذف المجلد من Git فقط، لا تحذف الملفات من قرصك إن كنت تستخدمها محليًا.)

## 2) ملف الجذر الميت `server.mjs`
السبب: نسخة قديمة/مكررة من نقطة التشغيل الحقيقية `backend/server.mjs`. لا شيء يستورده. نقطة تشغيل Render الحقيقية هي `backend/server.mjs`، والـ shim المطلوب هو `server.js` (CommonJS) — **لا تحذف `server.js`**.
الإجراء:
```
git rm server.mjs
```

## 3) مجلد الجذر المكرر/المعزول `tools/`
السبب: نسخة قديمة مكررة من `backend/tools/`. التنفيذ الفعلي يستورد من `backend/tools/registry.mjs` و`backend/tools/connectors.mjs`. النسخة الجذرية `tools/` غير مستوردة من أي مكان.
الإجراء:
```
git rm -r tools
```

---
ملاحظة: بعد الحذف، تأكد من أن `.gitignore` يحتوي على `dist/` (موجود بالفعل) لمنع إعادة تتبعه.
